# Workspace interaction and data integrity audit

November 19, 2026. Reviewed the public Agenetic app, Windows renderer and updater, Python companion, community request handling, team service and database access rules. The hands-on paths used disposable local data. GitHub records the browser and commercial checks for the exact revision in PR #7.

| Path | Finding | Change and regression coverage |
| --- | --- | --- |
| Read while zooming | World transforms, label metrics and the zoom percentage updated on different schedules. Hub background rings were also rebuilt when a gesture settled. | Keep title and status size steady in screen pixels, anchor the wheel at the pointer, retain a clear label slot and transform the existing depth layer. The wheel regression checks the anchor, type size and percent through motion and settle. |
| Explore a large graph | Hover reparsed wiki links from source text. Dragging a single node scanned every visible edge. Computing connection counts scanned the edge list once per node. | Index visible nodes and incident edges per projection, count degrees once, and deduplicate wiki links during parsing. Browser coverage includes 600 real notes linked by their titles. The layout unit fixture contains 1,500 nodes. |
| Navigate with a keyboard | Each node added another Tab stop. Space did not open the focused node, and a pointer crossing another branch could obscure the inspected one. | One graph Tab stop, directional arrow navigation, Home and End, Enter and Space. The camera reveals an off-screen keyboard target at the existing scale. Hover yields to the inspected branch and to keyboard focus. |
| First run and return visits | The guide trapped returning users. Focus skipped the new step heading. A failed preference write could advance the next step in memory. Photo selection had different handling in setup and profile settings. The 384-pixel brand image overflowed the identity page on a narrow screen. | Move focus to the heading or selected theme, persist progress before advancing and provide an exit on return visits. The brand image fits the sidebar and becomes a compact mark on phones. Both avatar entry points decode and crop photos locally. The browser tests exercise a failed write, retry, a narrow viewport and restart. |
| File a claim audit | Exports could use an ordinary source outside the active workspace. The presence of an old quote could be confused with a current review. | Use the workspace's visible source set, omit unavailable evidence text and hashes, and report the existing evidence-chain check separately from quote matching. Cache the text hash per source during export. |
| Share a workflow | An agent could pull in original documents outside the visible workspace. The file list appeared after collection. | Name linked dependencies and require confirmation before reading their original files. Stop an export if its workspace changes. A regression checks cancellation before attachment reads and successful inclusion after confirmation. |
| Restore a device vault | A synchronous write failure after queuing both store clears could leave a transaction able to commit. Inconsistent profile indexes could reach the replace step. | Abort the write transaction on synchronous failure. Validate profile IDs, active index, duplicate index entries and device identity. Browser coverage verifies that both profile records and original attachment bytes survive a failed restore. |
| Open a team workspace | A failed load sent signed-in users to the login form. Changing panels fetched the same team again. Overlapping loads could display stale state. | Keep a retry action, capture the requested team, ignore superseded loads and reuse loaded data when changing panels. Refresh remains available. |
| Request team services | An unbounded body read could allocate the entire request before the size check. Internal database action names could reach the generic dispatch path. | Cap bytes while reading the request stream and allow only supported public actions. Existing membership, role and device checks run for accepted actions. |
| Resume commercial checkout | An open checkout for a different quantity or billing period could be returned. An unpaid subscription could be mistaken for a team starting its first subscription. | Match the team, mode, price and exact seat count before returning an existing checkout. On a conflict show the existing terms when available and its expiry. Supply subscription presence for owners without exposing the Stripe ID. |

## Graph timing sample

A local Node 24 comparison used 1,500 in-memory notes and 7,500 distinct wiki links. With the same IDs, text and output counts on both revisions, median link construction fell from 300.9 ms to 6.3 ms. Computing connection counts for all 1,500 nodes fell from 151.0 ms to 0.6 ms. Six measured runs followed one warm-up. These timings cover JavaScript work outside the renderer. Browser frame times and physical touchpad behavior require separate measurement.

## Verification and release boundaries

The local Node suite covers evidence selection, review state, workflow packages, graph layout, backup validation, model handling and desktop update decisions. The Python companion tests use fixtures. The PostgreSQL integration suite exercises membership isolation, seat limits, retries, project revisions and revocation. Browser checks use an isolated vault and fixture team responses. The Actions artifact contains the run's checklist and theme and viewport captures.

| Release check | Evidence still needed |
| --- | --- |
| Windows navigation and inference | On a physical Windows device, compare a notched wheel and precision touchpad at 125% and 150% display scale. Measure frame times using a long-lived workspace. Run a supported GGUF on the target hardware and open, cancel and resume research from the UI. |
| Assistive technology | Follow the graph, wizard, inspector and focus return with NVDA on Windows. Check focus and contrast on installed community themes. |
| Desktop rollout | Install the signed candidate over an existing beta, reopen a real vault, confirm an update through the shipped feed and exercise rollback on a disposable installation. |
| Hosted billing and community | Deploy the reviewed team service to staging and complete a Stripe test checkout, delivery replay, seat change, invoice and invite. Use two staging accounts to check publishing, deletion and team isolation. |
| Duration and scale | Measure an all-day run, crash recovery and several concurrent teams under representative load. The synthetic graph and fixture tests establish specific behaviors and do not establish hardware capacity or a concurrency limit. |
